# 兽人战士 · 灰牙氏族（v1）

普通营地近战敌人。绿皮、獠牙、棕色皮甲造型，使用模组标准方块人形和石斧；不放大模型，不加发光、粒子或现代武器。设定为守卫氏族营地的战士，有自己的同伴和生活，不只重复喊打喊杀。

## 调用

本机游戏目录为 `D:\CPN\bmc5client\game`。使用这个目录启动客户端，以有 NPC 编辑权限的 OP 身份进入世界，拿复制魔杖右键地面：

**客户端 → 第 1 页 → 兽人战士_灰牙氏族_v1 → 生成。**

实际文件：`game/customnpcs/clones/1/兽人战士_灰牙氏族_v1.json`。
版本库备份：`pack/customnpcs/clones/1/兽人战士_灰牙氏族_v1.json`。
若列表已经打开，关闭后重新打开。客户端克隆只是一份模板，不会自动在世界中生成敌人。

首次执行 `python tools/client.py setup` 会从 pack 安装该模板；已存在的本地模板会被保留。想恢复此版本时，先备份本地同名文件，再复制 pack 内的文件。

## 实测记录

2026-09-30：原版模组隔离服务端 16 项检查通过。客户端克隆控制器可列出并读取此模板，魔杖生成逻辑可连续召唤两只；24 句中文往返保存不变。兽人正常步行接敌，连续 8 次命中固定测试靶，每次 5 点、间隔 30 tick，死亡后移除。结果见 [测试数据](validation/orc-warrior-results.json)。

无人测试时仅在隔离服为测试牛添加 Does It Tick 白名单，避免靶被性能优化暂停；用户客户端配置未改动。验证覆盖原模组读写、生成、选敌和近战逻辑；未进入图形客户端逐句检查气泡或试听声音。创造模式不挨打是模组原有规则。

客户端全包 `tools/client.py verify` 另报一项既有差异：`mods/mcef-cache/LOG` 与资源包锁定值不同，该文件是此前运行产生的浏览器缓存日志，本次保留原文件。其余清单条目（包括新增模板的存在性）通过该次扫描；新模板安装副本与实际测试导出文件的 SHA-256 一致。
